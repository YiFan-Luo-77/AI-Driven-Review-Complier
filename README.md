# AI-Driven Game Review Compiler

Final group project for **MATH-395 – Creating AI in the Loop**.

This application fetches game information from the Steam Store, uses OpenAI GPT-4o to generate a comprehensive game review, and optionally merges the player's own gaming experience and screenshots into the final output.

## Features

- 🔍 **Steam game search** – look up any game by title using the Steam Store API
- 🤖 **AI-generated review** – structured review (Overview, Gameplay, Story & Setting, Visuals & Audio, Value & Verdict) generated by GPT-4o
- ✍️ **Personal experience** – provide your own notes; the AI incorporates them into the review
- 📸 **Screenshot collage** – Steam screenshots and your own uploads are combined into a grid image shown alongside the review
- ⬇️ **Markdown export** – download the final review as a `.md` file

## Quick Start

### 1. Clone and install dependencies

```bash
git clone <repo-url>
cd AI-Driven-Review-Complier
pip install -r requirements.txt
```

### 2. Configure your OpenAI API key

```bash
cp .env.example .env
# edit .env and set OPENAI_API_KEY=<your key>
```

Alternatively, paste the key directly into the sidebar when the app is running.

### 3. Run the app

```bash
streamlit run app.py
```

Open the URL shown in the terminal (usually `http://localhost:8501`).
